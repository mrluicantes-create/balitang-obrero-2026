# Balitang Obrero 2026

Interactive 20-page newspaper with an uncut pages 10–11 center spread, page navigation, zoom, responsive mobile support, fullscreen where supported, and PDF download.

## GitHub Pages

In Settings → Pages, select Deploy from a branch, main, and /(root), then Save. All website files are at the repository root. No build command or paid service is required.

The PDF contains 19 sheets because the original center spread is preserved as one landscape sheet.
